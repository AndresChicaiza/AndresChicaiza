### 🚀 Proyectos destacados

- **[ERG Inventory ERP](https://github.com/AndresChicaiza/REEMPLAZAR-LINK)** — ERP full-stack (Django REST Framework + React) para una empresa real: facturación electrónica DIAN, inventario multi-bodega, nómina, producción y marketplace, con un asistente de IA (Groq) para consultas en lenguaje natural y un modelo de predicción de agotamiento de stock (scikit-learn).

- **[ChicaizaSuite](https://github.com/AndresChicaiza/REEMPLAZAR-LINK)** — SaaS de punto de venta e inventario multi-tenant (ASP.NET Core 8 / EF Core), con facturación electrónica integrada al SRI (Ecuador) con firma digital XML y un chatbot con IA.

- **[Salón de Estudio](https://github.com/AndresChicaiza/REEMPLAZAR-LINK)** — Plataforma de salas de estudio colaborativas en tiempo real: video/audio P2P vía WebRTC, señalización con Socket.io, autenticación con Firebase y pruebas de accesibilidad automatizadas.

- **[ScoutBot](https://github.com/AndresChicaiza/REEMPLAZAR-LINK)** — Analizador de partidos del Mundial 2026: usa Groq (Llama 3.3) y búsqueda web (Tavily) para generar análisis estructurado en JSON.
